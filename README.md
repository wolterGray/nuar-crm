# NUAR CRM

CRM массажной студии NUAR на React и Vite.

## Локальный запуск

Локально запускается только frontend. Все API-запросы идут напрямую в Hetzner backend:
`https://api.nuarr.pl`.

```bash
npm install
npm run dev
```

Создайте `.env.local` по примеру `.env.example`.

Минимальный `.env.local`:

```text
VITE_BACKEND_URL=https://api.nuarr.pl
```

Локальный backend/Postgres больше не поднимаются. Папка `backend/` хранит код,
который деплоится на Hetzner.

## Операционный flow

Типичный рабочий цикл в CRM:

1. **Новый клиент** — раздел «Клиенты» → добавить карточку (телефон, заметка).
2. **Запись** — календарь → новая запись или «Добавить визит» из карточки клиента.
3. **Завершение** — визит автоматически переходит в «окончен» после времени слота
   или вручную через статус; данные попадают в журнал оплат.
4. **Оплата** — раздел «Оплаты»: сумма, способ оплаты, долг, чаевые, комиссия Booksy.
5. **Статистика** — блок «Сегодня» и отчёт за период: поступления, долги, прогноз.

Цены услуг из каталога CRM автоматически синхронизируются на сайт nuarr.pl.
Контент сайта редактируется в админке lavandi, не в CRM.

## Продакшен

Frontend собирается командой `npm run build` и отдаётся Nginx на Hetzner.
Backend, база и авторизация тоже работают на Hetzner. Пароль владельца не
хранится в сборке CRM.

SPA fallback для `/reset-password` и внутренних маршрутов настраивается в
Nginx, см. `DEPLOY_HETZNER.md`.
